# Douaa Bejou — Portfolio

Personal portfolio site for Douaa Bejou, Ingénieure en Génie Industriel.

Built as a single-page scrolling experience with lazy-loaded sections, restrained
motion, and a warm industrial-editorial visual identity.

**Live:** https://portfolio-douaa.vercel.app

---

## Tech stack

| Layer | Choice | Version |
|-------|--------|---------|
| Framework | React | 19.1.1 |
| Build tool | Vite | 7.1.7 |
| Language | TypeScript | 5.9.3 |
| Motion | Framer Motion | 12.23.24 |
| Icons | Lucide React | 0.546.0 |
| Flags | country-flag-icons | 1.5.18 |
| Runtime | Node.js | 20.19.6 |

All dependency versions are pinned exactly — no `^` or `~`. See `package.json`.
